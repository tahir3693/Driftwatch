# Tech

## Stack
- React with Vite, JavaScript only (no TypeScript).
- Tailwind CSS for styling.
- Chart.js (with react-chartjs-2) for charts.
- Dexie for IndexedDB storage.
- Vitest for tests.

## Rules
- No backend.
- No network needed at runtime. Everything must work offline.
- All UI text is in English.
- No NASA logos or branding.
- No photos of people.
- Never read or print API keys.
